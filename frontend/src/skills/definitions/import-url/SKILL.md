# 导入链接

将网页内容通过 URL 导入到目标知识库。系统会自动抓取页面、提取正文、
清洗格式，然后进行分块、向量化和索引，使其可被检索。

## 支持的类型

- 公开网页（HTML）
- 微信公众号文章（mp.weixin.qq.com）
- 技术文档站
- 博客和文章

## 处理流程

1. 用户在聊天中粘贴链接，或通过附件菜单打开导入表单
2. 调用 `POST /api/knowledge-bases/{kb_id}/import-url`
3. 后端抓取页面、提取正文、入库处理
4. 返回成功或失败结果

## 注意事项

- 需要登录才能访问的页面无法导入
- 微信公众号文章需要特殊解析内嵌内容
- 页面越大处理时间越长
